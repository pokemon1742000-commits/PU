v1.0.2 Phiên bản hiện tại

  • Thêm nhận diện mới: logo ứng dụng, icon cửa sổ và phiên bản cạnh tiêu đề.
  • Dùng file MKAC Monthly Timesheet làm danh sách Job Code mặc định, không cần nạp thủ công.
  • Tách chức năng đổi mã duyệt PR thành trang riêng, có phân trang và loại bỏ liên kết.
  • Khôi phục trang quản lý cơ sở dữ liệu và nút xóa có xác nhận 3 bước.

v1.0.1 Phiên bản hiện tại

  • Thêm cập nhật tự động từ GitHub Releases.
  • Liên kết mã hàng cũ → mã thay thế theo từng dự án.
  • Đối chiếu theo PR mã mới và hiển thị PR/mã cũ gạch ngang.
  • Cải thiện phân loại Đủ, Thiếu, Thừa và xuất Excel.

v1.0.0 Phiên bản hiện tại

  • Phiên bản đầu tiên hỗ trợ nạp dữ liệu Mua Hàng, Quét Mã và Nhập Kho.
  • Đối chiếu số lượng, xác nhận mã gần giống và xuất báo cáo Excel.
